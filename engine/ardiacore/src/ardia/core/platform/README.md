# ArdiaCore Platform Adapters

This directory organizes platform-specific native implementations for the ArdiaCore engine:
- `windows/`: Windows implementations (Win32, Credential Manager, D3D12/Dawn, Chromium Views)
- `linux/`: Linux implementations (GTK4/X11/Wayland, libsecret, Vulkan/Dawn)
- macOS continues to use the existing `engine/ardiacore/src/ardia/core/*.mm` files.
