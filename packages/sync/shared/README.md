# Ardia Shared Cross-Platform Sync

Cross-platform folder-based file synchronization for Ardia Browser on Windows, Linux, and macOS.

### Features
- **Local / Cloud Folder sync**: Works with local directories, OneDrive, Google Drive, Dropbox, or Syncthing.
- **End-to-End Encryption**: AES-256-GCM record-level encryption with PBKDF2 key derivation.
- **Conflict Resolution**: CRDT-style Last-Write-Wins (LWW) conflict merging by timestamp.
- **OS File Watching**: Real-time sync notifications using native file system events.
